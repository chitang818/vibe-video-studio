# 输出目录（output）

- **每套作品一个子目录**：`output/{作品编号_作品名称}/`（如 `output/N0004_贝莱斯芽孢杆菌的产业化之路/`）。
- 子目录内：
  - `{作品编号_作品名称}.html` —— 动画页（可再编辑/微调）
  - `{作品编号_作品名称}.mp4` —— 成片（1080×1920/9:16）
  - `_work/` —— 中间产物（帧序列、音效 WAV、验证日志），录制/合成/验证脚本的输出放这里，不污染成品层。
- 交付给用户：HTML + MP4 两个文件。
- 命名规则见 RULES §1.6：有作品编号时「作品编号_作品名称」，无编号时用作品名称。
