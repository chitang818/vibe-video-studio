# 临时缓存区 (Temp)

本目录为 `vibe-video-studio` 运行过程中的**专用临时缓存与过程文件隔离区**。

## 目录用途
以下所有过程产生的非最终资产均统一落地于此：
- `frames/`：Playwright 无头录制时逐帧截图产生的中间图片帧序列
- `qa_probes/`：四边安全区与边界 QA 探针截图、自动复核报告
- `audios/`：FFmpeg 多轨混音试算产生的中间音频切片

## 安全清理规则
- 本目录已被 `.gitignore` 全局忽略；
- 执行 `python vibe.py clean` 将专门安全清空本目录内容，**绝不会误删或影响任何用户工程作品与原始素材**。
