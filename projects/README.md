# 作品工程目录

新任务使用 [AGENTS](../AGENTS.md) 与 [质量契约](../references/quality-contract.md)，默认新建 编号_名称_vN，不覆盖旧作品。原素材可从外部目录读取，工程内完整归档原声、原时间戳、原脚本与音效。

有 vibe.project.json 只代表高速协议工程。自动审核通过但未独立批准的作品仍是草稿；只有 pack 产生的签名发布目录可称正式发布包。历史文件夹不能因 HTML 存在就声称 READY。

示例和缓存不等于已批准作品。正式发布副本在 releases/，持久证据在 artifacts/quality/；clean 只处理临时缓存。
