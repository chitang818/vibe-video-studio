# 项目工程库 (Projects)

本目录为 `vibe-video-studio` 的**作品工程统一存储区**。

## 目录组织标准
当零散素材（未组织为独立文件夹）导入系统时，系统将自动在此处建档为自包含的独立工程文件夹：

```
📁 projects/
└── 📁 {作品编号}_{作品名称}/
     ├── 📄 {作品编号}_{作品名称}.html      (核心动效网页，数据全内联)
     ├── 🎵 *.wav 或 voice.wav            (主解说口播配音)
     ├── 📊 *_char_timestamps.json        (字级时间戳文件)
     ├── 📝 *.txt 或 script.txt           (文案脚本正文)
     ├── 🔔 sfx.json                      (毫秒级音效触发时刻表)
     └── 🎬 *.mp4                         (若在本地合成了成品视频)
```

## 与外部协同
- **外部文件夹导入**：若用户直接从外部路径导入已存在的作品文件夹，系统将直接就地生成，不在此目录额外复制冗余数据。
- **与 WeMediaForge 对接**：本目录下的任意子文件夹均可直接拖入 WeMediaForge【基础工具箱 - 网页处理】进行 GPU 硬件加速秒级出片。
