## 规则覆盖原则

详见 [制作规则](../.agents/rules/vibe-rules.md) 和 [门禁契约](quality-contract.md)。

- **自动检查**：时间连续、WAV 时长、节点边界、实际矢量范围、字号、文字/图形碰撞候选、字幕逐字一致与术语、节拍与时间戳引用、资源指纹、页面错误、声音输出、截图覆盖。
- **人工或 Agent 看图听音复核**：图示科学含义、叙事、术语断句、背景质量、真正的视觉推进、音效听感、手机可读性。必须逐场记录看到/听到什么，不能由自动脚本预填通过。
- **能力缺口**：共享 runtime 不支持的品牌背景、路径描线或声音处理，先记录实际限制；可在工程资产层制作等效表达，但不得用 metadata 假称已有实现。必须看图/听音验证，或阻止正式交付。
- **检查边界**：抽样、像素信号和几何候选不等于连续全片、人耳听感或 WeMediaForge 实际导出验收。不声称消灭所有未来问题。

## N0008 的重新制作方案

当前 v1/v2 保留为回归负例。后续新版本需要：重做三阶段开场；分类使用可辨识的功能图标；宿主供碳、互利交换、根皮层丛枝、根外菌丝探索分别编排；按原词设计 3–4 秒信息推进；去掉整片重复小苗；保留语义字幕与标点；通过自动检查后逐场复核，最后执行 pack。不要通过给旧版本补“已复核”字段把问题变成合格。
