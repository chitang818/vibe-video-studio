# 当前Canvas制作检查清单

默认动态PPT使用[制作入口](presentation-authoring.md)和presentation-profile.json。旧6–14秒、每2秒运动和每镜主图仅适用于knowledge-portrait-v1；新模式允许文字页和阅读停留，4–20秒页长、事件/停留≤10秒。

配合[R1–R11](../.agents/rules/vibe-rules.md)、[Profile](quality-profile.json)、[规则迁移清单](rule-migration.md)使用，不运行旧DOM截图流程。

- [ ] 原脚本、WAV、字时间原件保留，数字/单位/小数点完全一致。
- [ ] 沿用交付方式与顶部偏好；长标题显式语义分行，隐藏顶部不留空区。
- [ ] 左上角第X/N节显示，切点前后、倒退seek和重播同步；主标题区不混入HUD。
- [ ] 原稿决定开场，无虚构回顾；首推进≤1秒、第二次≤4秒。
- [ ] 分镜6–14秒、4秒内有真信息节拍，无正文连续2秒静止；不靠字幕/粒子/呼吸蒙混。
- [ ] 安全区/三区/字号/真实路径合规，长标题无默认折行和孤字，专业词不拆。
- [ ] 圆环中心仅数字符号、字号5.2%–5.8%、内环净空≥20px；图数/柱值分区。
- [ ] 每镜有解释图形，竖屏优先纵向条目；全部阶段与手机截图已查看。
- [ ] 背景、标题质感、完整转场按真实能力复核；默认粒子不冒充官方预设。
- [ ] 白名单WAV已归档；每切点whoosh，末镜完整chime，ding/pop限频、无越尾。
- [ ] 网页声源与输出信号存在，实际听音后才写听感通过。
- [ ] 暂停时钟停止，结束重播从首镜/首字幕开始，无旧状态残留。
- [ ] 结尾遵循原稿，CTA存在才有对应动作，不新增口播。
- [ ] audit自动错误清零，独立凭证与当前证据一致；needs_review仅是草稿。
- [ ] 完整新工程目录；缓存进temp，持久证据进artifacts/quality；真实MP4未执行不称验收。

- [ ] 字形缓存与留白参考逐像素一致，无削顶/缺底/左右笔画裁切，多行与组合字素回归通过；不得仅看文字框高度。

- [ ] 底部进度条、当前/总时长可见且可操作；暂停/播放中拖动、键盘Home/End与重播同步，手机控件不越界、不遮挡画面。

- [ ] 新模式按版式容量填充，图片页有已登记图片，文字页有imageNote；真实字号不缩小凑版。
- [ ] 独立卡片底板外边缘有清楚净空，默认56px、最少32px（1080画宽，Profile为准）；两至四项和入场中段均检查，不以未重叠代替间距达标。320/440手机上不连成整块；容量不足拆页。
- [ ] 素材策略与来源相符，原始来源/许可或生成记录已登记，搜图/生图实际调用与受控导入测试明确区分。
- [ ] 动效入场/强调与转场的起点、中段、终点已核对，稳定阅读不被误判。

- [ ] 题材动态背景真实存在并随时间变化；solid仅显式选择。默认标题和正文实际墨迹水平/垂直居中，入场及转场无双页重影。

- [ ] bio-bubbles在多个时间点覆盖画布分区，不集中在斜线/局部；全局运动像素通过不能代替覆盖率。

- [ ] 背景从固定模板库选择，版本/配方指纹一致；源模块与生成运行时一致；不同风格按各自QA区域验证，不用一套全屏阈值套全部背景。
# 默认网页视频流程补充

- [ ] intake差异已核对；分镜恰好覆盖原识别记录，原文/原声保持原件。
- [ ] 全片style与每镜brief/结构草图可查看，选择依据明确；不以长提示词代替构图。
- [ ] 素材来源/格式/呈现分别选择，真实工具与外部调用记录清晰；受限SVG仅静态转PNG。
- [ ] 单镜场景描述与全片一致；依赖变动后stale阻断；指定镜头重做能复用其他有效镜头。
- [ ] 实际构图/动效重复与节奏已看图复核，stage ready/技术0错误不代填审美或听感批准。
