# 可复用提示词模板（下次直接粘贴）

```
请制作一个 VIBE 知识视频的 HTML 动画页（自包含单文件，非 AI 文生视频），
用于抖音竖屏发布，规格 1080×1920（9:16）。

【素材】
- 文案：{粘贴文案，或说明素材路径}
- 配音：{WAV 文件路径}
- 字级时间戳：{JSON 文件路径，每字含 StartSeconds/EndSeconds/DurationSeconds}

【硬性要求】
1. 音频主时钟驱动：requestAnimationFrame 循环读 audio.currentTime；
2. 卡拉OK字幕：按字级时间戳逐字高亮，按标点断句（句末标点后重开窗口，
   短视频断句三原则：单行 4~10 字、超 10 字强制截断，意群完整、行首不落虚词，
   不足 3 字防碎行延伸）；字幕固定窗口、逐字高亮、绝不滚动；
   **标点规则**：行末断句标点不显示（断句点标点用换行代替），句末标点
   （。！？）只在句子最后一个字幕单元末尾显示，单元中间的标点正常显示；
   即字幕只显示文字，行尾不带标点，标点只在句尾出现；
3. 场景切换：按文案段落映射 N 个场景，时间点全部取自时间戳；
4. 开场（抖音规则·由文案决定）：先读文案开头，识别形态——钩子开场/直奔主题/系列回顾；
   首屏(0~1s)必须有钩子动效（钩子=全片最吸引人的信息点），禁止纯品牌名开场；
   **开场结构不套模板**（无"上期回顾"内容的文案禁止强行做回顾段）；
   所有阶段边界必须从时间戳精确读取；
5. **四边安全区 + 三区布局**（1080×1920，参照抖音/剪映安全规范）：
   **安全区外只允许背景，任何内容不得进入四边安全区**——
   顶部 ≥10cqh（状态栏/刘海）、底部 ≥14cqh（抖音底部UI/caption，字幕底线
   不得低于此线）、左右各 ≥8cqw（手机圆角/曲面/打孔 + 抖音右侧操作栏），
   全部内容居中在安全区以内（内容最宽 ≤84cqw）；
   画面垂直分三个独立区域（上区标题/中区内容/下区字幕），
   **三区互不重叠、彼此留足间隔（≥6cqh 净空），不得贴得太近**：
   - 上区（可选）：默认显示，只放作品整体总结性标题 + 当前第几节序号（如"第 2/8 节"）；
     **禁止放系列眉标/栏目名**（如"VIBE 知识大赏·农业篇 03"）、禁止副标题/要点行；
     若用户明确说不显示顶部，则成片只含中区+下区（中区顶从 10cqh 安全区开始）；
   - 中区：场景主内容垂直居中，**内容高度 ≤51cqh（990px）、宽度 ≤84cqw**，
     不侵入上/下区、不超左右安全区；超限场景压缩主图形/网格/文字行数，禁止溢出；
     开场与结尾画面同为中区内容，遵守同样约束；
   - 下区：字幕固定底部安全区上沿（bottom:14%，底线≥14cqh，不贴底、不挡抖音底部UI），
     容器 min-height 按单行行高（≈4.4cqh）设置，不超过 7cqw；
   - 概念区分：安全区=内容与四边边缘距离；三区间隔=上/中/下区之间净空（≥6cqh），中区内容须同时满足两者；
6. 重播时清除全部场景 active；场景 id 统一用连字符；
7. **场景内分波次动效**：每个场景 2~3 波入场（徽标弹入→标题淡入→卡片/数据 stagger），
   关键数字加脉冲强调，禁止一次性静态出现；任意连续 2 秒画面无变化即不合格；
8. **转场有可感知事件**：场景切换 = 旧场景淡出 + 新场景淡入 + 闪光/缩放，禁止生硬硬切；
9. **结尾互动**：CTA（点赞/关注/收藏/评论）弹入+循环脉冲；结尾内容按文案实际结尾——
   有下期预告用钩子短句，无则总结金句/利益点回扣；关注引导按需；
10. **音效轨与白名单规范**：
   - 严禁虚构未定义音效，仅允许使用 5 款白名单：`whoosh`（切屏转场）、`pop`（数字/卡片弹出）、`ding`（核心重点）、`chime`（结尾CTA）、`click`（微触击）；
   - HTML 内置 `VibeSound` 引擎：`setScene()` 自动播 whoosh，片尾自动播 chime；
   - 微动效可通过 `VibeSound.play('pop')` 强调关键数字，严禁密集滥用（同屏 ≤3 次，间隔 ≥0.6s）；
   - 混音端由 `scripts/mux.py` 自动毫秒级对齐混流；
11. 风格：{深色科技风/绿色农科风，明确主色，发光大字，粒子背景}；
12. **图案化表达（画面不能只剩文字）**：每个场景必须有图形化主视觉——
    - 数据用图形载体（占比→环形进度环/块状格，对比→双色柱，时间→倒计时环），禁止裸数字；
    - 概念用 SVG 图标+箭头流程图（机制→流程链，分类→图标网格，通路→节点连线），禁止纯文字卡片；
    - 抽象功能用具象隐喻（武器库=盾牌、打疫苗=针筒、抢地盘=棋盘占位）；
    - 全部图标内联 SVG 绘制（file:// 禁外链图片），统一线性风格+主题色；
    - 每个场景有氛围背景层（渐变+几何装饰+粒子，低透明度不抢戏）；
    - 主图形配循环动效（浮动/呼吸/旋转扫描/流光，同屏 ≤2 种）；
    - 文字行数 ≤2 行/屏（不含字幕），图形是主角；
13. 文案中的数字/数据必须原样呈现，不编造。

【交付前自查】
- 播放实测：开头1s有动效且首屏是钩子（非纯品牌名）、字幕逐字不滚动、场景切换、重播无残留；
- 音画同步：阶段/场景切换时间 = 字级时间戳；
- 竖屏布局无遮挡、顶部内容在安全区以下、场景内元素有波次动效；
- 转场 flash 实际生效（无恒 false 死逻辑）；
- 结尾 CTA 有动效与强引导；字幕与画面文字/术语一致无错字；
- **画面有图形化主视觉**：每屏非纯文字（数据有图表、概念有图示/隐喻、有背景氛围层）；
- 图标全部内联 SVG、风格统一、有循环动效，无外链资源。
```
