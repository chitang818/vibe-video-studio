# 踩坑清单（本项目血泪史，务必逐条对照）

| # | 坑 | 现象 | 根因 | 解法 |
|--|----|----|----|----|
| 1 | 场景 id 不一致 | 播放后"画面一直不变"，只有字幕在走 | JS 用下划线 `s_open`，HTML/CSS 用连字符 `s-open`，`getElementById` 找不到元素 | JS/CSS/HTML 的 id 全部统一用连字符 |
| 2 | file:// 不能 fetch | 数据加载失败 | file:// 页面禁止 fetch/XMLHttpRequest 读本地文件 | 文案、时间戳、场景表全部内联进 JS |
| 3 | 场景 active 残留 | 重播时旧场景文字叠加 | 切换只加 active 不移除旧场景 | startPlay 开头先移除全部场景 active |
| 4 | 文字堆叠遮挡 | 部分画面文字互相覆盖 | cqw 布局元素间距不足 | 逐场景实测，钥匙卡/标签/提示/字幕分层下移 |
| 5 | transform 覆盖 | 浮动动画把元素整体带偏半个身位 | 动画 keyframes 覆盖了 `translateX(-50%)` 定位 | 动画帧里保留定位 translate（如 `translateX(-50%) translateY(...)`） |
| 6 | 阶段时间拍脑袋 | 画面切换和配音对不上 | 用估算时间（1.4/5.8/9.8s） | 从字级时间戳精确读取（首字 1.87s），边界 = 1.87/7.35/14.87s |
| 7 | 浏览器截图有延迟 | 抓拍不到目标时间点的画面 | computer_use 截图调度有 3~5s 延迟 | 锁定 currentTime 或读 computed style 验证，不靠 sleep 抓拍 |
| 8 | 音频 ended 后 loop 停止 | seek 无效果，以为音画不同步 | 音频播完 state=ended，rAF loop 已停 | 验证前先确认音频在播；或刷新页面重新点播放 |
| 9 | AudioContext 手势门槛 | 音效不响 | 浏览器禁止无手势自动播放 | 全部音频/音效初始化放在"开始播放"点击后的 Promise 链里 |
| 10 | 无头 rAF 节流 | 无头模式下动画帧率低 | headless Chrome rAF 可能被节流 | 逐帧 seek 后 sleep 0.03~0.06s 再截图 |
| 11 | 环境 Python 无 playwright | `import playwright` 失败 | 默认 python 指向沙箱或未安装环境 | 先运行 `python scripts/doctor.py` 诊断，确保指向安装了 playwright 的 Python 解释器 |
| 12 | 开发备注泄漏进成片 | 成片画面底部出现"配音文件在 assets/voice.wav，转发时请连同文件夹"等文字 | 交付说明写进了页面 DOM（.foot/副标题/tips），录屏时全部入镜 | 开发备注（技术说明、转发提示、播放完成提示）不写进页面 DOM，或录制前移除 |
| 13 | 后台长任务卡死 shell | 后台录制异常退出后 PowerShell 工具持续超时 | 残留浏览器进程占资源/系统高负载 | 长录制用前台分段跑（每段 <5 分钟）；异常退出后先等系统恢复再继续 |
| 14 | Temp 目录脚本丢失 | `Temp\vibe_render.py` 找不到 | 系统临时目录被清理 | 录制脚本等可复用工具放项目目录（`_video\`）而非 Temp |
| 15 | ffmpeg 合成"失败"假象 | 编码统计正常但 exit 1 | 非致命警告/-shortest 截断提示 | 用 ffprobe 验证输出文件（时长/分辨率/音视频流）为准，不只看 exit code |
| 16 | 纯品牌名开场无钩子 | 开头 1~3 秒对陌生用户无吸引力，3 秒完播低 | 第 1 屏只放菌名/品牌名，没有数字/悬念/痛点 | 开场闪屏改放钩子（反差数字/悬念/痛点），品牌名降为辅助行 |
| 17 | 场景内元素一次性静态出现 | 长片（>60s）中后段画面只剩字幕变化，视觉疲劳 | 场景切换后 badge/卡片/数据同时出现，无波次动效 | 每场景 2~3 波入场（徽标弹入→标题淡入→卡片 stagger），关键数字加脉冲强调 |
| 18 | 结尾 CTA 纯静态 | 点赞/关注引导弱，互动率低 | CTA 无动效、无强引导文案 | CTA 弹入+循环脉冲；下期预告用钩子短句；加"关注不迷路" |
| 19 | 无点缀音效 | 成片只有人声，缺抖音节奏感 | 未规划音效轨 | 独立音效轨（转场 whoosh/数字 pop/结尾 chime）+ FFmpeg amix 混入 |
| 20 | 转场 flash 永不触发 | 场景切换只有淡入，无闪光转场（实测 N0003 全部切换无 flash） | `setScene` 中 `if(idx>0 && idx!==curScene+0)` 里 `curScene` 已先被赋值为 `idx`，条件恒 false | 判断写在使用旧值的位置：先判断再赋值（`if(idx>0 && idx!==prevScene)`），或去掉冗余条件 |
| 21 | 字幕与画面文案不一致（术语错字） | N0003 画面写"次级代谢产物"、字幕跟随文案写"刺激代谢产物" | 文案（script.txt）本身是错字，字幕数据从文案生成、画面文字人工修正为正确术语，两处来源不同步 | 制作前先核对文案术语（次级代谢≠刺激代谢）；字幕数据与画面文字必须来自同一份校正后文案 |
