# 交付前检查清单（每次必查）

- [ ] 点击播放后：开头 1 秒内有动效（钩子大字 / 图形运动），无长时间静态画面
- [ ] **开场第 1 屏有钩子**（反差数字 / 悬念 / 痛点 / 直奔主题的核心信息），不是纯品牌名/纯标题开场
- [ ] **开场结构由文案决定**：无"上期/接着讲"等内容时不强做回顾段；开场各阶段边界与时间戳一致
- [ ] 字幕逐字高亮，断句自然，**单行不超过 10 字**，无整段粘连、行首无虚词
- [ ] **无碎行单元**：字幕无 1~3 字碎行（顿号/逗号拆出的短单元已并入前段，如"促生、防病、修复"不会出现孤立的"促生""防病"行；句首首个单元除外）
- [ ] **字幕标点规则正确**：行末断句标点不显示（行尾无逗号/顿号/冒号），句末标点只在句子最后一个字幕单元末尾显示，单元中间的标点正常显示
- [ ] 场景随配音切换，切换时间与时间戳一致
- [ ] **任意连续 2 秒画面无变化即不合格**（波次入场/数据强调/转场/字幕推进都算变化）
- [ ] **场景内元素分 2~3 波入场**（徽标→标题→卡片 stagger，间隔 0.08~0.12s），关键数字有强调动效（breathe/pop），不是一次性静态出现
- [ ] **转场有可感知事件**（淡入+闪光/缩放），无生硬硬切
- [ ] **结尾 CTA 有动效 + 强引导**（弹入+脉冲；结尾按文案实际：下期预告用钩子短句，无则总结金句/利益点回扣）
- [ ] 各场景文字无堆叠遮挡（重点查标签、卡片、提示、字幕）
- [ ] 重播功能正常，无旧画面残留
- [ ] **三区布局无重叠**：上区（标题/章节序号）/中区（主内容）/下区（字幕）互不重叠，彼此净空 ≥6cqh，不粘连
- [ ] **中区不越界**：中区内容高度 ≤51cqh（990px）、宽度 ≤84cqw，超限场景已压缩（主图形缩小/网格收紧/文字精简），开场与结尾画面同样不越界
- [ ] **四边安全区合规**：顶部 ≥10cqh、底部 ≥14cqh（字幕底线不低于安全线）、左右各 ≥8cqw；**安全区外无任何内容（只显示背景）**，内容最宽 ≤84cqw 居中，逐场景截图核对不越界
- [ ] **顶部简洁合规**：上区只含作品总结性标题 + 第 N/M 节序号；无系列眉标/栏目名（如"VIBE 知识大赏·农业篇 03"）、无副标题/要点行
- [ ] **顶部可选模式正确**：用户明确说不显示顶部时，成片只含中区+下区，无空标题区残留
- [ ] 9:16 竖屏布局完整，无裁切；上区内容在安全区（≥10cqh）以下
- [ ] 配音文件路径正确（转发时连同 assets 目录）
- [ ] 转 MP4：帧率 ≥ 20、yuv420p、混入配音、时长与配音一致；有音效轨时 amix 混入成功
- [ ] **字幕与画面文字一致**：术语/数字逐条比对（字幕数据 vs 场景静态文字 vs 文案），无错字（如"次级代谢"误写"刺激代谢"）
- [ ] **转场动效实际生效**：代码逻辑无恒 false 死条件（flash 转场是否真的触发，而非只有淡入）
- [ ] **画面有图形化主视觉（非纯文字屏）**：关键数据有图表载体（环形/柱状/块状），概念有 SVG 图标/流程图，抽象功能有视觉隐喻
- [ ] 图标全部内联 SVG 绘制、风格统一（线性+主题色），无外链图片/字体
- [ ] 每场景有氛围背景层（渐变+几何装饰+粒子），不抢主视觉；主图形有循环动效（同屏 ≤2 种）
- [ ] 文字行数 ≤2 行/屏（不含字幕），图形是主角、文字是配角

## 验证方法要点

- 音画同步：真实播放 + 定点读取（播放中 `a.currentTime = X` 后读 data-phase / 字幕文本），不靠 sleep 抓拍。
- 字幕断句：逐句检查单行字数、行首是否落虚词、意群是否完整。
- 场景切换：对照字级时间戳逐一核对切换时刻。
- MP4 结果：用 ffprobe 验证输出文件（时长 / 分辨率 / 音视频流）为准，不只看 exit code。
